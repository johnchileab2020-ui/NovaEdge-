🤖 Nova EA — Auto Import

Once the NovaEdge EA is running on MT5, it writes your closed trades to a file called nova_trades.csv in your MT5 common files folder. Click the button below to load that file and sync any new trades into Nova.

📁 Where to find the file:
Windows: C:\Users\[You]\AppData\Roaming\MetaQuotes\Terminal\Common\Files\NovaJournal\nova_trades.csv
Or open MT5 → File → Open Data Folder → Common → Files → NovaJournal
📂 Load nova_trades.csv
Click to browse or drop the EA file here
Tip: Do this once after each trading session and Nova will pull in only new trades — no duplicates.
